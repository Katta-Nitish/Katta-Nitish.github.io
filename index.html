P.04

Self-Improving RAG Agent

This is where I stopped babysitting the model's answers and let it check its own work.

THE PROBLEM —A RAG system's first answer is often mediocre, and most setups have no way to notice that or try again.

WHAT I BUILT —A retrieval loop that grades its own answer with a second model, and automatically retries with a wider search when the score is too low — running fully offline, at zero API cost.

P.05

Agentic RAG System

The project where I actually learned to make an agent say "I don't know" instead of guessing.

THE PROBLEM —Most RAG demos retrieve-then-answer no matter what — even for ambiguous questions or ones the documents just don't cover.

WHAT I BUILT —A router that chooses between clarifying, retrieving, calling a tool, answering directly, or refusing outright — reranking results before they ever reach the model, and refusing when the evidence doesn't support an answer.

P.06

Local LLM Performance Predictor

The project where I stopped guessing whether a model would fit on my machine and started measuring it.

THE PROBLEM —Downloading a big local model and hoping it doesn't choke your machine is a bad way to find out it won't fit.

WHAT I BUILT —A benchmarking harness that measured real latency, RAM, and VRAM across 8 local models, trained regression models on the results, and now predicts hardware risk through a small API and dashboard before you ever load the model.
